
# Shop Ledger

A simple and user-friendly web application designed to help small shops and hotels manage customer credit records and daily transactions.

## Features
- Easy-to-use interface
- Customer credit tracking
- Simple transaction records
- Google Sheets integration (if configured)

## Technologies Used
- HTML
- CSS
- JavaScript
- Google Sheets
- GitHub
- Vercel
- Stitch
- Figma for UI design

## Live Demo
https://shopl-edger.vercel.app

## Purpose
To make customer credit management easier, faster, and more organized for small businesses.
